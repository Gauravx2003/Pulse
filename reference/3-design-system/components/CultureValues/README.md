# CultureValues

The 11 DO culture values as a radar (person vs team average) beside a 1–5 rubric score per value.

**Consumer provides:** eleven scores 1.0–5.0 in the fixed order (Outcome Ownership, Moral & Ethics, Decision Making, Problem Solving, Risk Appetite, Adaptability, Agility in Execution, Collaboration, Resilience, Resourcefulness, Discipline) and their weights, optional comparison series, period label, rater mix.

- Person series: `brand` stroke over `brand-soft` fill. Comparison: dashed `ink-muted`. Never more than two series.
- Scores come from the behaviour-anchored rubric (see *Measuring the 10 culture values*), not from activity data alone.
- Each row opens the evidence drawer: the examples, kudos and 360 comments behind the score.
- Show n of raters; hide a value's score when fewer than 3 raters (show "Not enough input").
