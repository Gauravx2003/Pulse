# IntegrationTile

One connected (or connectable) tool with what it feeds into Pulse and its sync state.

**Consumer provides:** a 2-letter monogram, tool name, one-line "what we read", status tone + text, and the action.

- Status: `ok` Connected · `accent` needs attention soon · `danger` sync failed (show the error code) · neutral Not connected.
- The mark is a monogram tile, **not the vendor's logo** — Pulse ships no third-party logos. Swap in official logo files only from each vendor's brand kit.
- Description states the data read, so people know exactly what is tracked.
