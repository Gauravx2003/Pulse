# RoadmapTimeline

A vertical list of an employee's past, current and planned growth milestones.

**Consumer provides:** items `{state: done|now|next, title, when, progress?, note}`; the track name.

- One `now` item at a time; it may carry a progress bar (0–100) fed by linked OKRs / Jira epics.
- `done` dots are filled `brand` with a check; `next` are outlined `border-strong`.
- Titles are outcomes ("Lead a cross-team epic"), not courses attended.
- Milestones are agreed in 1:1s; the employee can propose, the manager confirms.
