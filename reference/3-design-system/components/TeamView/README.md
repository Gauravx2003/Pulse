# TeamView

The manager's team screen: team KPIs over a TeamHeatmap, with tabs for stale work and culture.

- Sort people by utilization, highest first, so overload is seen first.
- Every KPI names the people behind it ("Priya 128%, Sara 109%") so the manager can act.
- Suggest a rebalance (move issues from Over to Under people) — never auto-reassign.
